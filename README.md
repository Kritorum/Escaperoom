# 🗝️ Escape Room Web Project

Ein interaktives Escape-Room-Webspiel, das als **Abschlussprojekt in Gruppenarbeit** für die Fachhochschulreife an der Landrat-Gruber-Schule, Dieburg entwickelt wurde.

> ⚠️ **Hinweis zum Server-Status:**  
> Der ursprüngliche PHP-Server ist **nicht mehr aktiv**. Einige dynamische Funktionen (wie Registrierung, Login, Live-Datenbankabfragen oder Speicherstände) stehen daher aktuell nicht mehr zur Verfügung.
